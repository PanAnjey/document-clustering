# Исправления для Vision Transformer Training

## 🐛 Найденные и исправленные проблемы

### 1. **Строка 475 - `invalid literal for int() with base 10: 'other'`**
**Проблема:** Функция `compute_class_weights` пыталась преобразовать строку "other" в int
**Решение:** Добавлена обработка исключений при создании маппингов классов

### 2. **Строка 367 - `name 'num_gpus' is not defined`**
**Проблема:** Функция `build_loaders` использовала переменную `num_gpus`, но она не была передана как аргумент
**Решение:** Добавлен параметр `num_gpus` в сигнатуру функции и передача из `main()`

### 3. **Строка 398 - `AssertionError: Input height (240) doesn't match model (224)`**
**Проблема:** ViT Base ожидает входной размер 224×224, но в config было IMAGE_SIZE = 240
**Решение:** Изменено `IMAGE_SIZE: int = 224` и `CROP_WINDOW: int = 224`

---

## ✅ Исправленные параметры в config.py

| Параметр | Было | Стало | Обоснование |
|----------|------|-------|-------------|
| `OUTPUT_CLASSES` | 5 | **4** | Только 0°, 90°, 180°, 270° (без "other") |
| `IMAGE_SIZE` | 240 | **224** | ViT Base ожидает 224×224 |
| `CROP_WINDOW` | 240 | **224** | Соответствует IMAGE_SIZE |

## 📝 Примечания

- **ViT Base** использует стандартный размер входа 224×224
- Если хотите использовать больший размер (384), нужно:
  - Изменить `MODEL_NAME` на `"vit_base_patch16_384"`
  - Установить `IMAGE_SIZE = 384` в config.py
  - Увеличить VRAM до ~24GB

- **Attention mechanism** критичен для решения проблемы 0° vs 180°
- **VerticalFlip аугментация** (50% вероятность) улучшает различение симметричных классов
