## ViT-Large 384

### Архитектура
- Vision Transformer Large (307M параметров)
- Размер входа: 384×384
- Предобученные веса: IMAGENET1K_V2
- Additional: attention-механизм для улучшения 0° vs 180°

### Параметры обучения
- Эпохи: 100 (early stopping на 30)
- Batch size: 16 (effective: 32 на 2 GPU)
- Learning rate: 3e-5
- Weight decay: 0.05
- LR scheduler: cosine (eta_min=1e-7)
- Loss: CrossEntropyLoss
- Аугментация: ROTATION_AUG, VERTICAL_FLIP, SKEW, BORDER

### Результаты

|---------|----------|
| **Accuracy** | **99.63%** |
| Ошибок | 11 из 2991 |
| Время обучения | ~30 мин (30 эпох) |
| Время инференса | 33.5s |
| Размер модели | 1.2 GB |

## Сравнение

| Метрика | ViT-Large | EfficientNet-B1 |
|---------|-----------|-----------------|
| **Accuracy** | **99.63%** | 99.57% |
| Ошибок | 11 | 13 |
| Время инференса | 33.5s | **15.8s** |
| Размер модели | 1.2 GB | **26 MB** |
| Параметры | 307M | 7.8M |

### Преимущества ViT-Large
- Выше точность (99.63% vs 99.57%)
- Меньше ошибок на классе 0° (5 vs 8)

### Преимущества EfficientNet-B1
- В 2 раза быстрее (15.8s vs 33.5s)
- В 46 раз компактнее (26 MB vs 1.2 GB)
- Подходит для edge/embedded устройств

---

## Выводы

1. **ViT-Large 384** — лучший выбор для production (99.63%)
2. **EfficientNet-B1** — альтернатива для ограниченных ресурсов (99.57%)
3. Обе модели показывают отличные результаты на классе 270° (100%)
4. Основная путаница: 0° ↔ 180° (симметричные документы)
