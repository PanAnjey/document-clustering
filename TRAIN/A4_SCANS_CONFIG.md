# Vision Transformer для A4 сканов (384×384)

## 📊 Почему 224×224 было недостаточно?

| Параметр | Значение | Проблема |
|----------|----------|----------|
| **A4 документ** | ~210×297 мм | Стандартный формат документов |
| **Типичный скан** | 300 DPI = 2480×3508 px | Высокое разрешение |
| **ViT Base 224** | Потеря ~99% деталей! | Текст становится нечитаемым |
| **Мелкий текст** | <10pt | Практически исчезает при 224×224 |

### Визуальное сравнение:

```
A4 скан (300 DPI):    ████████████████████  2480px
ViT Base 224:         ████                  224px (91% потеря!)
ViT Base 384:         ████████              384px (85% потеря, но лучше)
```

## 🎯 Преимущества 384×384 для A4 сканов

### ✅ Качество текста

- **Мелкий текст (<10pt)**: Чётко виден, не размыт
- **Таблицы**: Границы и ячейки различимы
- **Печати/штампы**: Детали сохраняются
- **Подписи**: Распознаются лучше

### ✅ Различение 0° vs 180°

- **Заголовки**: Видны детали шрифта (засечки, формы букв)
- **Логотипы**: Сохраняют форму при повороте
- **Нумерация страниц**: Чётко видна ориентация

### ✅ Адаптивность к качеству сканов

| Качество скана | 224×224 | 384×384 |
|----------------|---------|---------|
| **Высокое (600 DPI)** | Хорошо | Отлично |
| **Среднее (300 DPI)** | Удовлетворительно | Хорошо |
| **Низкое (150 DPI)** | Плохо | Удовлетворительно |

## 💡 Рекомендации для A4 сканов

### ✅ Когда использовать ViT Base 384×384:

1. **Высокое качество сканов** (≥300 DPI)
2. **Мелкий текст** (<12pt) в документах
3. **Сложные макеты** с таблицами, графиками
4. **Критична точность** для 0° vs 180°
5. **Есть 2xGPU** с достаточной памятью

### ⚠️ Когда использовать ViT Base 224×224:

1. **Низкое качество сканов** (<150 DPI)
2. **Простые документы** без мелкого текста
3. **Ограниченная память GPU** (<24GB VRAM)
4. **Быстрый прототип** (нужна скорость обучения)
