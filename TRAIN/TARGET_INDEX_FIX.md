# Исправление ошибки `Target 180 out of range [0, 4)!`

## 🐛 Проблема

```
[ERROR] Target 180 out of range [0, 4)! Clipping to 0.
```

Эта ошибка возникает потому что **target - это индекс класса (0-3), а не угол!**

---

## 🔍 Причина ошибки

### Неправильная логика:

**Было:**
```python
# Получаем угол из индекса
orig_angle = self.idx_to_angle[class_idx]  # например, 180

# Поворачиваем
new_angle = (orig_angle + a) % 360  # например, 0

# ОШИБКА: используем угол как target!
target = int(self.angle_to_idx[new_angle])  # должно быть индекс класса, но получается угол
```

**Проблема:** `angle_to_idx` маппит углы к индексам классов ImageFolder, которые сортируются **алфавитно**:
- `'0'` -> индекс 0
- `'180'` -> индекс 1 (потому что '1' < '2' < '9')
- `'270'` -> индекс 2
- `'90'` -> индекс 3

Но когда мы делаем ротацию, `target` должен быть **индексом класса**, а не углом!

---

## ✅ Исправление

### Правильная логика:

```python
# 1) Получаем исходный угол из индекса класса ImageFolder
orig_angle = self.idx_to_angle[class_idx]  # например, 180

# 2) Поворачиваем изображение
a = 90 * k
if a:
    img = img.rotate((-a) % 360, expand=True)

# 3) Вычисляем новый угол после поворота
new_angle = (orig_angle + a) % 360  # например, 0

# 4) Находим индекс класса для нового угла
if new_angle in self.angle_to_idx:
    target = int(self.angle_to_idx[new_angle])  # например, 0
else:
    print(f"[WARN] Угол {new_angle} не найден в angle_to_idx. Используем класс для 0°.")
    target = self.angle_to_idx.get(0, 0)

# 5) VerticalFlip меняет метку: 0° ↔ 180°, 90° ↔ 270°
if self.mode == "train" and C.VERTICAL_FLIP_AUG and random.random() < C.VERTICAL_FLIP_PROB:
    img = img.transpose(Image.FLIP_TOP_BOTTOM)
    
    # Определяем индексы классов для каждого угла
    angle_0_idx = self.angle_to_idx.get(0, 0)
    angle_180_idx = self.angle_to_idx.get(180, 1)
    angle_90_idx = self.angle_to_idx.get(90, 3)
    angle_270_idx = self.angle_to_idx.get(270, 2)
    
    # Меняем метки при вертикальном флипе
    if target == angle_0_idx:
        target = angle_180_idx
    elif target == angle_180_idx:
        target = angle_0_idx
    elif target == angle_90_idx:
        target = angle_270_idx
    elif target == angle_270_idx:
        target = angle_90_idx

# 6) Финальная проверка: target должен быть индексом класса [0, n_classes)
num_classes = len(self.classes)
if not (0 <= target < num_classes):
    print(f"[ERROR] Target {target} out of range [0, {num_classes})! Clipping to 0.")
    target = max(0, min(target, num_classes - 1))

return self.post_tfm(img), target
```

## 📊 Пример работы маппингов

### ImageFolder сортирует классы алфавитно:

| Имя класса | Индекс | Угол |
|------------|--------|------|
| `'0'` | 0 | 0° |
| `'180'` | 1 | 180° |
| `'270'` | 2 | 270° |
| `'90'` | 3 | 90° |

### Маппинги:

```python
idx_to_angle = {0: 0, 1: 180, 2: 270, 3: 90}
angle_to_idx = {0: 0, 180: 1, 270: 2, 90: 3}
```

### Пример ротации аугментации:

| Исходный угол | Поворот (k) | Новый угол | Индекс класса |
|---------------|-------------|------------|---------------|
| 180° (класс 1) | k=2 (180°) | (180+180)%360 = 0° | angle_to_idx[0] = **0** ✓ |
| 90° (класс 3) | k=1 (90°) | (90+90)%360 = 180° | angle_to_idx[180] = **1** ✓ |
| 270° (класс 2) | k=3 (270°) | (270+270)%360 = 180° | angle_to_idx[180] = **1** ✓ |
