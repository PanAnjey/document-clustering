# Отчёт: Эксперимент с SigLIP2

## Дата: 2026-07-01
## Модель: google/siglip2-so400m-patch14-384

---

## Описание эксперимента

SigLIP2 — это модель для сопоставления изображений и текста (contrastive learning). 
Проведены два эксперимента:
1. **Zero-shot** — использование без обучения на задаче ориентации
2. **Обученная** — дообучение классификатора на том же датасете, что и ViT-Large

---

## Zero-shot подход

### Метод
- Созданы 4 текстовых описания для каждой ориентации (0°, 90°, 180°, 270°)
- Для каждого изображения вычислялось сходство с каждым описанием
- Выбиралась ориентация с максимальным сходством

### Результаты

| Метрика | Значение |
|---------|----------|
| **Accuracy** | **20.33%** |
| Ошибок | 2383 из 2991 |
| Время | 399s |

### Per-class метрики

| Класс | Всего | Правильно | Accuracy |
|-------|-------|-----------|----------|
| 0° | 1732 | 208 | 12.01% |
| 90° | 568 | 154 | 27.11% |
| 180° | 353 | 57 | 16.15% |
| 270° | 338 | 189 | 55.92% |

### Вывод
Zero-shot подход не работает для определения ориентации документов. 
Модель не способна различать ориентации без специального обучения.

---

## Обученная модель

### Метод обучения
- Замороженный vision encoder (requires_grad = False)
- Обучаемый классификатор поверх [CLS] токена
- Архитектура: Linear(1152 → 512) → ReLU → Dropout(0.3) → Linear(512 → 4)
- Оптимизатор: AdamW, lr=1e-4
- Early stopping: patience=10

### Результаты

| Метрика | Значение |
|---------|----------|
| **Accuracy** | **70.81%** |
| Ошибок | 873 из 2991 |
| Время | 588s |

### Per-class метрики

| Класс | Всего | Правильно | Accuracy |
|-------|-------|-----------|----------|
| 0° | 1732 | 1502 | 86.72% |
| 90° | 568 | 334 | 58.80% |
| 180° | 353 | 208 | 58.92% |
| 270° | 338 | 74 | **21.89%** |

### Confusion Matrix

```
         pred:   0°   90°  180°  270°
  true   0°  [1502   92  130    8]
  true  90°  [  71  334   51  112]
  true 180°  [  81   34  208   30]
  true 270°  [  38  168   58   74]
```

### Анализ ошибок
- Класс 270° — самая большая проблема (21.89%), часто путается с 90° (168 ошибок)
- Класс 0° — относительно лучше (86.72%), но всё равно много ошибок
- Модель систематически путает 90° ↔ 270°

---

## Сравнение с ViT-Large 384

| Метод | Accuracy | Ошибок | Время |
|-------|----------|--------|-------|
| **ViT-Large 384** | **99.63%** | **11** | 33.5s |
| SigLIP2 (zero-shot) | 20.33% | 2383 | 399s |
| SigLIP2 (обученная) | 70.81% | 873 | 588s |

---

## Выводы

1. **SigLIP2 не подходит** для определения ориентации документов
2. **Zero-shot не работает** — модель не понимает геометрическую ориентацию
3. **Обученная модель** значительно хуже ViT-Large (70.81% vs 99.63%)
4. **Причины низкой точности:**
   - Замороженный encoder (не fine-tuned)
   - Архитектура оптимизирована для contrastive learning, не классификации
   - Размер модели (4.5 GB) не даёт преимущества без полной fine-tuning
