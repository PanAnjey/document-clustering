# Компактный промпт определения ориентации документа (для gemma-4 / vision-моделей малого размера)

Сокращённая версия промпта из `consolidated_orientation_prompt.md` — тот же смысл и те же 7
наиболее частотных критериев (98–99% → 33% встречаемости в исходной выборке из 1979 промптов),
но без повторяющихся формулировок и лишних пояснений. Рассчитан на модели с ограниченным
контекстом и упрощённым следованием длинным инструкциям (gemma-4 и подобные).

```
Ты — эксперт по определению ориентации сканов документов. Определи, на сколько градусов
изображение повёрнуто по часовой стрелке относительно правильного положения: 0°, 90°, 180° или 270°.

Правило: элемент, который в правильной ориентации находится вверху, при 90° оказывается
справа, при 180° — внизу, при 270° — слева. Элемент внизу: при 90° — слева, при 180° — вверху,
при 270° — справа.

Проверь признаки по таблице (пропускай неприменимые, например «Таблица» при её отсутствии):

| № | Критерий | 0° | 90° | 180° | 270° |
|---|---|---|---|---|---|
| 1 | Строки текста / буквы | горизонтально, слева→направо, буквы прямые | вертикально, сверху→вниз, буквы повёрнуты по часовой | горизонтально, справа→налево, буквы вверх ногами | вертикально, снизу→вверх, буквы повёрнуты против часовой |
| 2 | Заголовок | вверху | справа | внизу, перевёрнут | слева |
| 3 | Подписи/печати/штампы | внизу, печать читается нормально | слева, печать повёрнута по часовой | вверху, печать перевёрнута | справа, печать повёрнута против часовой |
| 4 | Таблица | заголовки столбцов сверху, строки горизонтальны | заголовки справа, строки вертикальны | заголовки снизу, строки горизонтальны (перевёрнуто) | заголовки слева, строки вертикальны |
| 5 | Логотип/бланк | правый верхний угол | правый нижний угол, повёрнут по часовой | левый нижний угол, перевёрнут | левый верхний угол, повёрнут против часовой |
| 6 | Поля страницы | верхнее поле уже нижнего | правое поле уже левого | нижнее поле уже верхнего | левое поле уже правого |
| 7 | Футер/реквизиты | внизу листа | слева | вверху листа | справа |

Алгоритм:
1. Для каждого применимого критерия выбери один угол (0/90/180/270) — это голос.
2. orientation = угол с наибольшим числом голосов.
3. confidence = голоса_за_orientation / число_применённых_критериев.
4. correction_angle и correction_direction: 0°→(0, "none"); 90°→(90, "counterclockwise");
   180°→(180, "clockwise"); 270°→(90, "clockwise").
5. При равенстве голосов — реши по критериям 1 и 2 (самые надёжные), confidence умножь на 0.5.

Выведи ТОЛЬКО JSON без пояснений и текста вокруг, строго по схеме:

```json
{
  "orientation": 0,
  "correction_angle": 0,
  "correction_direction": "none",
  "confidence": 0.0,
  "votes": {"0": 0, "90": 0, "180": 0, "270": 0},
  "applied_criteria": 0,
  "key_evidence": [
    {"criterion_id": 1, "criterion_name": "Направление текста", "observation": "..."}
  ],
  "contradictions": [
    {"criterion_id": 1, "criterion_name": "...", "indicated_angle": 90, "possible_reason": "..."}
  ]
}
```
```

## Что убрано по сравнению с полной версией и почему

| Убрано / сокращено | Обоснование |
|---|---|
| Критерии 9–15 полной версии (артефакты скана, списки, нумерация страниц, дата/номер, цифры, доп. маркеры, рукописные пометки) | Каждый встречается в исходной выборке менее чем в 25% промптов (артефакты — 24,7%, остальные — 0,6–12,7%); вклад в точность голосования минимален, а токены на их описание — существенны. |
| Раздел «Общая структура документа» (порядок блоков) | Дублирует информацию критериев 2 (заголовок) и 3 (подписи/печати) — те же позиции, но другими словами. |
| Развёрнутая методология и таблица статистики | Не нужна модели-исполнителю, важна только для документации; вынесена в отдельный полный файл. |
| Повторение 4 вариантов критерия как отдельных абзацев | Заменено на строку компактной таблицы — та же информация в разы меньшим числом токенов. |
| Подробные текстовые описания правил заполнения JSON-полей | Сохранены только сами названия полей и краткое правило подсчёта; смысл полей понятен из примера и имён ключей. |

## Оценка компактности

- Полная версия (`consolidated_orientation_prompt.md`, раздел 5, тело промпта): ≈ 1 750 токенов.
- Компактная версия (этот файл, содержимое блока кода): ≈ 550 токенов.
- Сокращение ≈ в 3,2 раза при сохранении 7 из 15 критериев, покрывающих совокупно наибольшую долю
  признаков (98,4% / 98,2% / 93,0% / 79,4% / 75,3% / 45,7% / 42,7% встречаемости в исходной выборке).
