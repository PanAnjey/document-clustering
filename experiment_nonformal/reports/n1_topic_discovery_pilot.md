# N1: открытие тем с нуля для неформализованных документов (пилот)

Выборка: 499 документов (125/группу, seed=42) из PDF_Text + PDF_Tables + Excel_Xlsx + Word (docx/doc/rtf/odt).
Метод: Qwen3.5-4B свободно придумывает тему документа (zero-shot, без каталога) -> nomic-embed -> HDBSCAN -> слияние центроидов (sim>=0.92) -> c-TF-IDF топ-слова.

|---|---|
| pdf_text | 125 |
| pdf_tables | 125 |
| excel_xlsx | 125 |
| word | 124 |

## Итог кластеризации

- Сырых кластеров HDBSCAN: 4
- После слияния близких центроидов (sim>=0.92): **4 тем**
- Шум (не вошли ни в одну тему): 290 (58.1%)
